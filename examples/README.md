# StreamHub examples

Self-contained, statically-hostable examples for StreamHub. Each folder is
independent: edit its `config.js` (set `baseUrl`, `wsUrl`, `app`, `room` to
your StreamHub), then host the folder on any static host — S3, Netlify, nginx,
GitHub Pages — or open `index.html` locally. No build step.

These bundles ship with **placeholder** config; the dashboard's per-app download
(GET /apps/:app/examples/:id.zip) hands you the same bundle already wired to a
specific app.

## Examples

- **webrtc-publish/** — WebRTC publish: Publish camera/mic to a room over WebRTC (low latency).
- **webrtc-play/** — WebRTC play: Subscribe/play a live room over WebRTC (low latency).
- **hls-player/** — HLS player: video.js HLS player for a room (higher latency, CDN-friendly).
- **audio-radio/** — Radio (master + listener): Audio radio: master goes on air with the mic; listeners tune in.
- **cctv-grid/** — CCTV grid: Low-latency grid of N live cameras (comma-separated rooms).
- **live-shopping/** — Live shopping: WebRTC viewer + chat/reactions data channel + buy button.
- **telemedicine/** — Telemedicine 1:1: Private 1:1 room joined with a pre-minted ephemeral token.
- **radio-player/** — Radio player: Embeddable audio-only listener on the public listen token.
- **conference/** — Conference (N-to-N): Google-Meet-style meeting: pre-join, tiles, screen share, chat.

Generated by `go generate ./cmd/build-examples` (streamhub-core-go) from
`internal/samples` — do not edit by hand.
